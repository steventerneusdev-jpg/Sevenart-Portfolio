# 📸 Guide des images pour le carousel photo

## 📁 Dossier pour vos images
Placez vos photos dans : `src/assets/carousel-photos/`

## 🎯 Recommandations techniques

### Format d'image
- **Format recommandé** : WebP (compression optimale)
- **Format alternatif** : JPG (si WebP non disponible)
- ❌ Évitez PNG (trop lourd pour des photos)

### Dimensions
- **Largeur** : 1200-1600px maximum
- **Hauteur** : 800-1000px (format paysage recommandé)
- **Ratio** : 16:9 ou 3:2 idéal pour le carousel

### Poids par image
- **Maximum** : 150-200 KB par image
- **Idéal** : 80-120 KB par image
- **Total recommandé** : < 2 MB pour toutes les images

### Nombre d'images
- **Recommandé** : 12-15 images
- **Minimum** : 8 images
- **Maximum** : 20 images (au-delà, le chargement peut ralentir)

## 🛠️ Comment optimiser vos images

### Avec des outils en ligne (gratuit)
1. **TinyPNG** (https://tinypng.com) - Pour JPG/PNG
2. **Squoosh** (https://squoosh.app) - Pour convertir en WebP
3. **CloudConvert** (https://cloudconvert.com) - Conversion batch

### Avec Photoshop / Lightroom
- Exporter en qualité 70-80%
- Redimensionner à 1400px de largeur
- "Enregistrer pour le web"

### Avec des outils gratuits
- **ImageOptim** (Mac) - gratuit, simple
- **GIMP** (Windows/Mac/Linux) - gratuit
- **XnConvert** (Windows/Mac/Linux) - conversion batch gratuite

## 📝 Convention de nommage (optionnel)
Pour garder les choses organisées :
- `photo-01.webp`, `photo-02.webp`, etc.
- ou par thème : `mariage-01.webp`, `lifestyle-01.webp`, etc.

## ✅ Checklist avant import
- [ ] Images redimensionnées (largeur ≤ 1600px)
- [ ] Format WebP ou JPG
- [ ] Poids < 150 KB par image
- [ ] 12-15 images sélectionnées
- [ ] Images placées dans `src/assets/carousel-photos/`

---

💡 **Astuce** : Choisissez des images variées (portraits, paysages, événements, lifestyle) pour montrer l'étendue de vos compétences photographiques.
